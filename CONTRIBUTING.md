# Contribuire la Legal Toolkit Bundle

Mulţumim pentru interes. Acest proiect este construit pentru comunitatea
juridica si academica romaneasca. Acceptam contributii in urmatoarele
categorii.

## Contributii bine-venite

1. Skill-uri noi pentru sub-domenii juridice (drept civil, penal,
   administrativ, fiscal)
2. Imbunatatiri ale skill-urilor existente (lista neagra termeni AI in
   romana, pattern-uri halucinare nou identificate)
3. Subagenti specializati pe domenii (fact-checker fiscal, fact-checker
   contencios)
4. Templates Project Instructions Cowork pentru alte tipuri de documente
5. Traduceri ale documentatiei in alte limbi europene
6. Rapoarte de bug si pattern-uri de halucinare noi descoperite

## Cum contribui

1. Fork repository pe GitHub
2. Creeaza branch pentru contributia ta (feature/skill-fiscal,
   bugfix/regex-pattern)
3. Adauga sau modifica fisierele relevante
4. Testeaza local cu Claude Desktop, Cowork sau Code
5. Trimite Pull Request cu descriere clara

## Format commit messages

Foloseste prefix descriptiv:
- skill: pentru modificari skill-uri
- agent: pentru subagenti
- script: pentru scripts Python
- doc: pentru documentatie
- fix: pentru bug-uri
- chore: pentru curatare sau structura

Exemplu: `skill: adauga reguli specifice pentru drept contraventional`.

## Cod de conduita

Acest proiect respecta standardele academice si profesionale juridice.
Limbaj respectuos, fara atacuri personale, focus pe substanta tehnica.
